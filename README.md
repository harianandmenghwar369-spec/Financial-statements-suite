# Financial Statements Suite

A professional Excel model containing all three core
financial statements — fully linked and formula-driven.

## Statements included

### Income Statement (Profit & Loss)
- Revenue, COGS, Gross Profit
- Operating expenses breakdown
- EBITDA and Net Profit calculation
- Monthly and annual view

### Balance Sheet
- Current and non-current assets
- Current and long-term liabilities
- Owner's equity and retained earnings
- Auto-balances with the income statement

### Cash Flow Statement
- Operating, investing, and financing activities
- Net cash position
- Linked to balance sheet cash balance

## Tools used

- Microsoft Excel
- Advanced formulas (INDEX, MATCH, OFFSET)
- Cross-sheet formula linking
- Professional formatting & layout

## How to use

1. Download the Excel file
2. Enter your business data in the Input sheet
3. All three statements auto-populate
4. Print-ready layout included
